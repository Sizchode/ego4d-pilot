# 独立新读者评审

评审范围：只阅读 `rw-readable-draft.md`，未阅读其他文件、打开链接或搜索。以懂基本计算机视觉、不了解此前讨论的读者身份评价可读性；不核验文献事实，也不评价尚未完成的方法是否已经成立。

## 1. 我读到的问题与研究设想

**错误发生机制。** 两扇外观相似、实际处于建筑不同侧面的窗，被错误地当成同一组空间点。重建程序为了满足错误匹配，连相机位置也一起算错，可能得到错误的建筑结构。由于相机和空间点都可以共同调整，错误解仍可能具有很小的重投影误差，因此常规几何误差检查不一定能排除它。这条因果链由正文直接说明，无需猜测。

**C 照片的作用。** C 是同一批已有照片中的额外证据：它同时展示两扇窗及其空间关系。圆钟和铭牌帮助把 A、B 中的窗分别对应到 C 中的左窗和右窗，从而对“这两组特征属于同一扇窗”的判断提出反证。VLM 提出冲突和可疑匹配，几何程序进一步检验，确认后才解除错误关联并重新求解。C 不是新增拍摄，也不是直接提供正确相机位置的答案。

这里有一处小的补读：我把“并且能辨认出：A 中圆钟紧邻 C 的左窗，B 中铭牌紧邻 C 的右窗”理解为 C 中也能认出相同圆钟和铭牌，并据此建立跨照片对应。正文没有逐字说清“C 中可识别出同一个标识”，需要读者补上这一步，但后续意图仍然明确。

**现有工作与拟议问题的区别。** 几何方法已经会过滤匹配、优化和重算模型；学习方法也已经能用两张或多张照片识别错误关联，因此“调用重建工具”或“利用图像消歧”都不能单独构成贡献。ThinkGraphs 的区别是它在已知相机位置的前提下合并重复对象记录；这里要处理的是错误匹配已经影响相机求解的情况。拟议研究要检验：在现有方法仍会失败的样本上，VLM 能否凭图像位置线索定位具体错误匹配，并使后续几何求解真正改善相机。Agent 的额外价值则取决于继续找证据是否改变修复决定。正文并未声称已经优于现有方法，这一点无需猜测。

**明确未定事项。** 匹配候选如何产生、下一张照片如何选择、区域判断如何落实到匹配点、接受修改的检验和停止条件，都尚未设计完成。与已有图像消歧方法共用后端的接入方式、包含自然错误且具有可信相机参考的测试样本集合，以及正确恢复的误差门槛也未确定。ETH3D 是否有足够相关错误样本尚待确认。这些是清楚列出的研究空缺，不是需要读者猜测的隐藏步骤。

**验证思路。** 先区分识别错误图像对、恢复相机和改善表面几何三个层次，分别使用相应数据和参考。相机评估同时看位姿精度和正确注册图像数量，以避免靠删掉困难照片获得表面上的改善。对照分为完整重建系统之间的比较，以及在相同照片、工具和求解器下对不同判断／查证方式的比较；后者用于检验 VLM 和多步过程是否各有实际增益。评估包含全部运行成本，参考答案仅用于离线评分。相机没有改善时，不能用对象记录或图像对分类的改善代替相机恢复结论。以上均可直接从正文读出。

## 2. 可读性结论

**能独立读懂。** 不需要先熟悉所列论文，便能理解错误如何产生、为什么重投影误差不足以排除它、C 提供什么新增证据、VLM 与几何程序各承担什么角色，以及研究最终要证明什么。先讲具体错误，再说明已有方法边界，随后列出假设、方法空缺和实验判据，阅读顺序自然。

**没有阻碍整体理解、必须重写的具体句子。** 唯一需要轻微推断的是上面引述的圆钟／铭牌句：它把跨图像身份对应与单图中的相邻关系压在同一句里。若要进一步消除歧义，可以明确说 C 中也能识别出 A 的圆钟和 B 的铭牌；这属于局部表达改进，不影响独立理解。

读后仍不能写出一套可运行算法，但正文明确承认这是一项研究设想，并逐项列出待设计内容。我不把算法尚未完成视为文字不清。文献之间是否还存在更强的重叠、所选数据是否最终足以支撑实验，也不能由这次只读草稿的可读性评审确认。
