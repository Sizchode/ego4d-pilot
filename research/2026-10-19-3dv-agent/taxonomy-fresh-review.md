# 独立读者评审

评审对象：`rw-taxonomy-draft.md`。只阅读该文件，没有读取其他材料、访问链接或核验文献真实性。以下判断基于一名懂基本计算机视觉、不了解此前讨论的读者能从正文获得的信息。

## 1. 我的独立复述

**问题是什么。** 重复结构会让重建程序把不同物理表面的特征连在一起，进而算错相机。错误相机与错误三维点仍可能相互适配，所以重投影误差小不代表重建正确。作者希望利用同一批照片中的标识、周边布局和其他视角，找出这种已经影响相机的错误关联，并检验修正后相机是否真的改善。本文不打算解决所有重建失败，只继续研究重复结构造成的错误对应。

**已有方法做什么。** 按正文描述，几何方法通过重建冲突发现问题并恢复模型；共视消歧方法判断图像是否拍到同一表面并筛选图像对；学习过滤方法用视觉及几何、图上下文识别错误约束；学习先验与几何融合方法将局部几何估计接入全局相机求解；VLM 对象关联方法在相机已知时合并重复对象记录。它们的输入证据、修改对象和输出层次不同，不是对应五种互斥的错误。

**唯一候选贡献是什么。** 用可核查的图像证据定位具体错误关联，最终改善已被这些关联影响的相机求解。比已有图像对消歧更细的定位、允许相机本身出错，是作者提出的研究区别，但还不是已证明的创新。VLM 是可能实现这一步的工具；多步 Agent 只有相对一次判断确实改变修复决定并改善结果时，才获得支持。正文没有把 VLM 和 Agent 各算成一个贡献。

## 2. 结论：能独立读懂

全文的问题、范围、现有方法和待验证假设能够独立串起来，不需要此前对话补足主线。我的通过判断只针对可读性与论证边界，不表示算法贡献已经成立、实验已经可执行，或文献描述已经核实。

错误类型与方法分类没有实质混淆。正文先明确二者回答不同问题，又说明论文可以跨方法类别，最后把研究范围收窄到重复结构错误对应。方法类别的抽象层次并不完全一致，例如“VLM 对象关联修复”同时包含工具和任务层次，但表前的“按主要机制分类”及“可跨类”提示足以避免将它读成严格、互斥的分类体系。

代表工作的基本作用及与拟议研究的关系也足够清楚。读者能看出“恢复流程已存在”“多视图上下文已存在”“视觉与几何结合已存在”“对象记录修复不等于相机修复”这几条界线。正文没有靠声称其他方法不会看图来抬高 VLM，也没有把增加工具调用步骤本身当成贡献。

没有发现把尚未证明的 VLM／Agent 优势写成事实的地方。“可能有用”“才有额外价值”“还没有成立的算法贡献”以及控制器对照共同约束了结论。尤其保留非语言模型和一次性 VLM 对照，使读者可以区分图像证据的价值、语言模型的价值和多步决策的价值。

## 3. 必要的局部修改

1. **明确候选贡献中的“具体错误匹配”是什么单位。** 文中交替出现匹配、关联、图像对约束、匹配点和对象区域。读者能理解总体目的，但无法确定最终交付的是两幅图中的点对应、跨图的特征轨迹，还是图像对中的局部区域。这直接关系到“比图像对判断更细”到底细在哪里。建议在第 3 节用一句话给出拟定位单位；如果尚未决定，应明确列为尚未确定的输出单位，而不要让它显得已经确定。无需为此虚构实现算法。

2. **限定“几何程序验证后才执行修改”的含义。** 开头已经说明错误模型也可能具有小重投影误差。后文这句容易让人误以为几何程序能自动判定修复正确，与开头产生局部张力。应说明执行前验证属于待设计的一致性／可执行性检查，不能仅凭重投影误差证明语义关联正确；修复是否有效仍由独立参考下的相机评测判断。具体准入条件可以继续保留为开放问题。

以上是两处影响主张精度的局部补充，不需要重写整篇。首次展开 SfM、VLM，以及用一句话说明 Agent 在本文中特指按反馈继续选图和检查的控制流程，会进一步降低阅读门槛，但不构成本次独立理解的障碍。

## 4. 最终稿复核

重新完整阅读修改后的同一份草稿，未查阅其他研究材料或访问链接。

- **输出单位的问题已解决。** “已有匹配列表中的具体点对”明确了待定位对象，也说明 VLM 不必生成像素坐标。现在能够区分图像对筛选、具体点对诊断和对象记录合并三个输出层次；对象区域怎样对应到匹配点仍被如实保留为方法设计问题。
- **几何验证表述的问题已解决。** 新增的“不能仅凭重投影误差下降接受修改”直接回应开头的反例，并明确独立观测验证规则尚待设计。结合这段限制，“几何程序验证后才执行修改”可以理解为拟议流程，而不是已经拥有可靠正确性判定器的事实陈述。

**最终结论：能独立读懂，两处必要意见均已解决。** 错误类型与修复方法仍区分清楚，唯一候选贡献仍是通过图像证据定位影响相机的错误匹配，VLM／Agent 的额外价值仍作为待验证假设。就本次可读性与论证边界复核而言，没有剩余的必要改写要求；这不构成对算法成立或文献真实性的背书。
