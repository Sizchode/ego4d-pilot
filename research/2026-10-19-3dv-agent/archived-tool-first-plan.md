# Training-Free SfM 修复最终实验方案

固定范围｜2026-10-19｜尚未运行实验

任务固定为静态 RGB 多视图的相机注册不足与错误匹配修复，输出相机和稀疏点云。预训练 VLM 组织现有工具，依据执行反馈继续、撤销或停止；不训练新模型，允许标准几何优化。比如两面相似窗户被拼到一起，系统检查原图与对应，再重验可疑图像对并重建。

研究位置：[AgenticIR](https://openreview.net/pdf?id=3RLxccFPHz) 已用工具反馈修复 2D 图像，[Think3D](https://arxiv.org/html/2601.13029v5) 已有 3D 工具推理；本项目直接评价修复后的相机。要检验的是同一工具集下选择与反馈的收益，不把工具数量或通用 Agent 循环作为新意。

## 1. Benchmark 与输入协议

| 数据 | 固定规模与划分 | 作用 |
| --- | --- | --- |
| [PhotoTourism / IMC](https://github.com/ubc-vision/image-matching-benchmark) | 官方 validation 场景开发；官方 test 中固定 100 组，每组 25 张图像 | 检验注册和匹配修复；属于固定子集实验，不声称完整官方成绩。 |
| [ETH3D high-resolution](https://eth3d.ethz.ch/overview) | 公开参考的 13 个 training 场景，整场景输入；全部用于跨数据集测试 | 检验室内外泛化；不使用这些场景调流程或阈值。 |

测试样本按场景均衡、固定种子抽取，提前保存图像清单及数据版本；全量评价选定样本，不按初始失败或最终收益挑样本。各方法得到相同图像与公开内参，参考外参只交给离线评估器。ETH3D 在此用于自定义 SfM 评价，不报告为官方 MVS 榜单；PhotoTourism 的参考来自大规模重建，有自身偏差。

## 2. 四个工具与固定初始状态

初始状态统一由 [hloc](https://github.com/cvg/Hierarchical-Localization) 构建：NetVLAD 每图 top-10 检索（不足则取全部），SuperPoint + LightGlue 匹配，再运行 COLMAP。缓存特征、匹配、初始重建与日志。Agent 只操作图像对及初始化，不生成像素坐标，不拆分单条三维点轨迹。

| 接口 | 实际组件 | 可执行内容 |
| --- | --- | --- |
| inspect | hloc 可视化 + 几何统计 | 查看指定原图、匹配叠图、注册状态、连接和 track/误差统计。 |
| match_pairs | SuperPoint 缓存 + LightGlue + 几何验证 | 对指定的尚未匹配图像对计算对应；新约束在重建时生效。 |
| verify_pairs | [Doppelgangers++](https://doppelgangers25.github.io/doppelgangers_plusplus/) + 两视图几何验证 | 返回可疑图像对的共视分数和几何支持，交给 Agent 判断。 |
| reconstruct | COLMAP mapper、三角化、过滤与 BA | 应用停用边列表和可选初始化图像对，重新求解；保存新旧快照。 |

## 3. Agent workflow 与预算

VLM 固定为 [Qwen3-VL-32B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-32B-Instruct)，冻结权重；模型版本、提示词、图像分辨率和解码参数仅在 PhotoTourism validation 上确定并冻结。每次先看原图缩略图、注册状态、图连接和误差摘要，再输出工具名、图像/图像对 ID 与理由。工具返回实际结果；每次重建保存快照，VLM 根据前后证据继续或撤销，最后选择一个快照作为输出。

每个 episode 最多 6 次 VLM 调用，最后一次用于停止及选择输出；最多 3 次额外 SfM 求解。新增 LightGlue 匹配和 DG++ 验证分别最多 2N 个图像对（N 为输入图像数，且不超过可用候选数）。无效调用也占调用预算。几何残差只提供证据，不自动批准修改；回退由 VLM 决定，测试真值不得用于选择动作、停止或挑选快照。

## 4. Baseline 与控制实验

| 方法与年份 | 固定运行方式 | 比较目的 |
| --- | --- | --- |
| Doppelgangers++（CVPR 2025） | 穷举 SP/LG 图像对，DG++ 筛边，再用统一 COLMAP 求解 | 现成消歧工具用足是否已经足够。 |
| [MP-SfM](https://github.com/cvg/mpsfm)（CVPR 2025） | 官方 sp-lg_m3dv2 配置，完整系统运行 | 与利用深度/法向先验的鲁棒 SfM 比较。 |
| [GLUEMAP](https://github.com/colmap/gluemap)（CVPR 2026） | 官方默认 Pi3 配置，开启 DG++，完整系统运行 | 与融合局部预测和全局优化的近期系统比较。 |

文献 baseline 年份按正式会议计，均为 2025 年及以后；DG++ 预印本首发于 2024 年。三项均有官方代码。DG++ 使用上述统一后端，MP-SfM 与 GLUEMAP 使用官方推荐配置并固定版本及预训练权重；不为本测试集训练或校准模型。它们按完整系统报告精度与实际成本，不声称计算量相同。

控制实验共享初始重建、日志、图像、工具与第 3 节预算上限：固定流程按检索顺序补匹配→DG++ 筛边→重建；一次性 VLM 看初始状态后制定完整计划，执行中不重新规划；我们的多步 VLM 使用执行反馈调整。固定流程的筛选阈值和初始化次序在开发集冻结。初始结果仅作为改善/退化的参照，不另列旧论文 baseline。

## 5. 指标、消融与完成标准

主指标为相对位姿 AUC@5°/10°/20°，每对误差取旋转角与平移方向角的较大值；缺失相机、跨独立组件的图像对计失败。配合报告注册覆盖、相对初始 AUC 改善/不变/退化比例、总时间及 VLM token 与推理成本。先按场景汇总，再跨场景平均；不以注册率或重投影误差单独宣称修复成功。

仅增加“多步 VLM 去掉图像输入”的消融；一次性计划已检验反馈价值。VLM 各变体以 3 个固定随机种子运行，报告均值与波动；预算包含失败尝试及最终选择，并分别记录初始与修复成本。完成范围就是两套数据、三项近期方法、两项控制实验和一项图像消融；不加入动态、密集重建或额外工具。
