# 实例身份、重复结构与文本线索：VLM 能增加什么？

核查日期：2026-10-19。以下区分论文已展示的现象、由这些现象推导的候选任务，以及尚无实证的 VLM 增量。所有假设例子均不是声称论文已经复现了相同失败。

## 结论

“VLM 看两张图判断是不是同地点/同对象”已有直接先例，不能再当作空白。最具体的正面证据来自 ThinkGraphs：VLM 利用图像与几何状态修复对象 track 身份；但输入相机位姿已知，未证明能修复 SfM 相机或错误对应关系。向未知相机恢复推广，需要处理几何状态本身可能错误的问题，不能简单把该模块接到 COLMAP 后宣称解决。

重复建筑 + 门牌文字是一个直观例子，但 VLM 必要性弱：OCR + 文本布局 + 几何验证已明确解决。可能有余地的是不同语义角色的证据冲突：门牌是身份线索，临时海报不是；但这也只是待验证假设，并且必须对照非语言学习型融合，而非弱数值阈值。

## 例一：两份相同包装 vs. 同一个物体被重建成两份

### 已有直接实证

ThinkGraphs App.C Fig.6 给了真实实例：不同角度的皮椅与部分可见电器产生碎片 tracks，critic 正确合并；垂直叠放的相似盒子保留为两个实例。它也误将小盒子与大物体合并，原因是大物体的 AABB 过度覆盖。该证据支持 VLM 对“外观+空间关系”做有用判断，同时暴露它可能被错误几何误导。[来源](https://arxiv.org/html/2606.31471v1)

### 推广到 reconstruction 的具体问题（尚无实证）

输入照片中有两个同款包装盒。一条错误 track 把两个不同盒子的印刷图案关联，导致相机拉近/局部几何合并。另一种情况则是同一盒子的正反面没有关联，造成重复对象。

VLM 可能用同时出现证据、折痕/贴纸、遮挡边界和邻近物体辨别身份。例如，同一原始帧中可同时看见两个分离实体，可反驳“这两个 track 都是同一个实体的重复副本”。但这不是通用逻辑规则：同一帧也可能包含镜像，分割也会把一个实体拆成多个区域，必须先验证观测语义。

### 动作与增量边界

- 工具动作：定位跨实例错误对应、拆分 tracks、禁止指定跨实例对应、重估受影响相机和局部 BA。不是把所有包装盒纹理都 mask 掉。
- 真正增量：从已知 pose 对象图的 merge/keep，扩展到“身份假设与相机几何互相约束”，并最终改善相机/几何而非只改善节点数。
- 风险：如果纯重识别+instance constraints 已达到相同结果，VLM 没有必要；一次看图分类成功也不证明 agent 多步必要。

### 同输入对照与反事实

- 同输入：ThinkGraphs critic、IRIS-style instance association、DINO/re-ID +几何图模型、Doppelgangers++/MVDG；它们获得相同 crops、原始图像及状态。
- 将图中盒子的几何重叠故意扰动但保留 RGB：模型是否盲从错误状态？
- 移除可区分贴纸/同时出现帧：模型应降低确定性，而不是保留原判断。
- 两实体真的相同 vs. 相同类别但不同实例；同时考察错误 merge 和错误 split。
- 以标注实例及对应关系验证诊断，以固定 backend 的相机/几何验证修复。仅 scene-graph consistency 不足。

## 例二：相同走廊、不同楼层；“同一文字”究竟是什么证据？

### 假设的具体失败

两层办公室结构一致，每层都有同样的消防门、EXIT、同款海报。重复特征产生假的 loop closure，压扁楼层或错接走廊。某些图能看到不同楼层/房间编号，另一些只能看到共同广告内容。

### 为什么几何统计不够，但这不自动支持 VLM

重复平面和纹理可支持看似一致的局部匹配。OCR 得到“201”和“301”就可能足够；TXTLCD 已利用 ID 文本以及重复 generic 文本的空间配置，TextGeo-SLAM 也处理相同文本的错误 loop。因此“VLM 会读门牌”不是贡献。[TXTLCD](https://arxiv.org/html/2410.15869v1)、[TextGeo-SLAM 作者机构](https://www.gml.ac.cn/kydt/745.html)

### 还可能存在的增量（弱假设）

文字内容相同，但载体与语境不同：房间永久标牌、临时展览海报、广告屏幕上的房间号码。VLM 可能把字符串绑定到载体，判断其适不适合作为地点身份约束，而非只比较 OCR 字符串。还需结合已有状态检查哪些错误对应恰好落在这些区域。

- 工具动作：重新提取高分辨率局部证据、将重复广告区域的匹配降权/排除，保留永久标识关联，重验候选 loop，固定 backend 优化。
- 同输入对照：OCR+几何文本图、OCR+learned carrier classifier、文字/实例/几何联合 GNN、Breaking Déjà Vu 的 pair verifier。
- 反事实：相同字符移到广告载体上，判断是否变化；替换房间号但固定所有非文字图像，是否只改变涉及该标识的匹配；遮蔽编号后是否承认不可判。
- 若增量只是改善 OCR 准确率，应归属于感知工具，不能归因于错误理解。

此例优点是解释清楚，缺点是已有工作覆盖厚，而且多步 Agent 的必要性最弱。

## 例三：同一地点换海报/店招，被误拆为两个地点

### 假设的具体失败

跨时间拍摄同一门面，门框与墙角保留，招牌和橱窗内容变化；视觉判别器把变化当作不同实体，导致两个 component。相反，同一连锁品牌在不同街区使用相同门面，则不能因店招相同而合并。

### 最近工作已经覆盖到哪里

Breaking Déjà Vu 已明确要求 VLM 识别永久结构、忽略动态或外观变化、比较布局，并在 AmsterTime 等跨时间数据上评测。它直接削弱“VLM 能理解变化不是新地点”的新颖性。[来源](https://arxiv.org/html/2607.12818v1)

可能的新任务是从地点判别走到局部修复：识别变化表面、保留稳定结构约束，跨时间重建相机而不强迫所有表面静态。需要区域级对应关系和几何结果，而非再输出 same-place Boolean。多状态重建和长期定位已有庞大文献，本轮未完成该分支核查，不能据此宣布 gap。

工具动作：按变化区域拆分/屏蔽 tracks，用稳定背景重新估计跨分量变换，保留时段特定几何。对照应包括动态/变化区域分割 +固定恢复、Doppelgangers++/MVDG、VLM pair audit。反事实要同时包含“同地换招牌”和“异地同招牌”，不能只做容易的一侧。

## 评测材料及边界

- VisymScenes/Doppelgangers：适合不同地点的相似表面；其地理元数据评价不能等同高精度相机 GT。
- ThinkGraphs 使用的 ScanNet/Replica：可验证对象 identity 修复；提供 pose 的原协议不能直接验证未知相机恢复。
- TXTLCD 开源采集：8 段室内、半室外及跨楼层轨迹，有 Leica 先验地图注册参考。需要公平处理 LiDAR/IMU 是否可给各方法，RGB-only 不能直接拿其原始数值横比。[方法与数据](https://arxiv.org/html/2410.15869v1)
- AmsterTime/Nordland：适合长期地点判别；不足以单独验证精确多视图恢复。

Breaking Déjà Vu 的性能数字需谨慎：方法只接受/拒绝 top-1，没有引入替换候选；其“after filtering Recall@1”提升不能直接理解为全 query 标准召回提升。应优先讨论接受集合精度、coverage、FAR，并保留全 query 分母。在其任务中，也没有端到端 SLAM 轨迹/地图修复实验。[§III–V](https://arxiv.org/html/2607.12818v1)

## 对主问题的建议

这一分支最有价值的是找到“同类不同实例”与“同实例不同观测”的错误，但它已不是空白。值得进一步追究的区别是：VLM 能否把身份证据定位到造成相机失败的具体 tracks，并在错误几何状态下保持正确，而不是仅对已知位姿对象地图做 merge/keep。必须把这个问题与恢复操作解耦，防止 toolkit 自己完成了所有判断。

若需要马上举出最直观、已有证据支持 VLM 增量的例子，应引用 ThinkGraphs 的椅子/电器/叠放盒子，同时清楚说它已经有人做过、仅证明对象图修复。不要把它包装成我们尚待提出的创新。
