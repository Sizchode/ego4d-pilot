# 独立新读者审读

审读对象：`rw-readable-draft.md`。只阅读该文件，没有打开链接、查阅同目录材料或询问作者。以下判断针对稿件的可读性与内部论证，不核验所引论文和数据集的事实准确性。假设读者懂基本计算机视觉，但没有参与研究讨论。

## 一、仅凭正文，我读到的研究设想

### 1. 具体错误如何发生

建筑转角两边各有一扇相似的窗。A、B 实际拍的是不同窗户，但重建程序把它们的窗角建立了错误对应，把不同物理点当成同一个三维点。错误对应进一步影响相机位置和三维结构的求解，使墙面被错误拼接。相机与三维点可以共同适应这组错误对应，所以重投影误差较小仍可能对应错误的场景解释。

这一因果链不需要我补猜。正文也明确把它称为假设例子，没有声称已经找到或复现这个具体失败案例。

### 2. 照片 C 为什么有帮助

C 同时呈现转角两边的两扇窗，给 A、B 原本分离的局部观察提供了共同参照。A 中窗旁的圆钟和 B 中窗旁的方形铭牌，可以在 C 中定位到两处不同的窗旁，因此支持 A、B 拍的是不同窗户。C 的作用不仅是“再看一张图”，而是让两个局部观察能够在同一画面内比较空间关系。

这里我补入了一个条件：A、B 中的标识确实能与 C 中的相应标识可靠对应，且其与窗户的关系足够明确。仅凭“一张有钟、另一张有铭牌”不能推出两扇窗不同；同一扇窗附近也可以同时有两个标识。正文写了“分别对应两处位置”和“支持”，并在后面承认不能据此直接批准删点，所以我将这理解为候选证据，而不是充分判据。这个理解有文本依据，但例子还可以把条件说得更明确。

### 3. 已有方法已经做什么

稿件将现有工作分成三类：几何方法已经会过滤错误匹配、优化相机与点，也已有针对重复结构及模型拆分重算的工作；学习方法已经能从两张或多张图像判断是否看到同一表面，也可能识别例子中的错误；VLM 已经能在相机位置已知的地图中判断对象身份并合并重复记录。

因此，调用重建工具、利用图像消歧、让 VLM 判断物体身份，这些动作单独都不是稿件提出的新贡献。正文没有把现有方法描述为必然看不懂这个例子。

### 4. 拟研究的增量是什么

拟验证的增量是：在现有方法仍失败的情况下，让 VLM 结合图像内容及空间关系提供证据，定位会影响相机求解的错误匹配，再交给固定的几何程序修改，最终改善相机恢复。

Agent 是进一步的待验证设计：信息不足时，主动从已有照片中寻找 C 一类的补充证据，或调用局部验证工具；多步查证必须改变修复决定并带来收益，才值得作为贡献。正文没有保证 VLM 比专门学习模型更强，也没有保证多步比一次判断更有效。

我能读懂这个研究假设，但无法据此认定新颖性已经成立。尤其文中自己说 MVDG 已利用多张图像消歧，因此“有 C”本身不是区别。真正需要实验建立的差别，是 VLM 或查证策略在相同信息条件下是否提供额外收益。正文的第二层对照与这一问题相符。

### 5. 什么还未确定

作者明确未确定：待检查匹配的筛选方式、下一张照片的选择方式、语义区域到匹配点的对应方式、修改的接受条件和停止规则。具有目标自然错误且有可信相机参考的样本集合、“正确恢复”的阈值，以及 ETH3D 是否包含足够目标错误，也都未确定。

这些缺口使它不能作为可直接实现的方法说明或完整实验协议，但不是读者没看懂。作者已明确标记它们为尚待设计；不能因为研究设想还没有完成算法，就要求其伪装成完成状态。

### 6. 实验如何检验

图像对数据先检验是否能识别错误关联，但不替代匹配点级或相机级结论。PhotoTourism 用位姿误差配合正确注册图像数，检查相机是否改善、是否通过舍弃困难图像取得表面收益；ETH3D 作为补充检查表面准确性和完整性。正文也披露了这些参考与标签的局限。

对照分两层：完整系统之间比较最终表现；固定照片、工具和求解器后，再比较固定流程、非语言模型、一次性 VLM 与多步 VLM，以考察决策方式的贡献，同时计入总运行时间。可信参考只用于评分，不参与选动作。

这足以让我理解如何证伪核心假设：如果只改善图像对判断或对象记录，相机没有改善，核心主张不成立；如果非语言或一次性方法效果相当，就不能据此强调 VLM 或 Agent。具体如何把消歧模型接成可比较的完整系统，正文还没有说明。

## 二、结论：可以独立读懂

作为一份短篇 related-work 研究设想，这份稿件可以独立读懂，无需整体重写。一个没有背景的读者能够说明失败机制、额外照片提供什么证据、现有工作与拟研究问题的关系，以及什么结果才算支持研究假设。它也明确区分了研究目标与尚未完成的设计。

这个结论不等于“方法已成立”或“已有可执行实验方案”。正文最有价值的边界是：新贡献尚待证明，且不能由分类正确直接跳到相机恢复成功。阅读中没有发现必须依靠作者口头补充才能接通的核心论证断裂。

## 三、仍会造成局部歧义的原句

### A. 照片 C 的证据强度：文字还可更明确

> “A 中窗旁的圆钟、B 中窗旁的方形铭牌，在 C 中分别对应两处位置。这些线索支持它们属于两扇不同的窗。”

“两处位置”是两个标识的位置，还是已经确定的两扇窗的位置？不同标识占据不同位置，本身不能排除它们位于同一扇窗附近。结合上一句 C 同时拍到两扇窗，我能够按作者意图读通，但仍需补入标识分别紧邻 C 中不同窗户的关系。这里属于例子中证据条件略有省略；后文把接受修改列为未定问题，避免了直接从标识差异跳到删匹配的错误推论。不是整段逻辑已经成立的充分证明，也不是整体不可读。

### B. “删点”与解除匹配不是同一个操作：文字没有交代

> “读出不同标识也不能直接批准删点。”

前文说的是“解除这些关联，重新计算相机和三维点”，此处突然写“删点”，容易让读者不确定拟修改的是匹配边、二维观测还是整个三维点。该句的谨慎态度清楚，但操作名词不一致。若本意只是强调不能直接执行修复，应保持与前文相同的操作表述；若确实另有删点操作，就需要交代它与解除关联的关系。

### C. 完整系统比较的组成：文字没有说明

> “第一层比较完整系统：COLMAP、GLUEMAP，以及专门消歧的 Doppelgangers++、MVDG。”

前文把后两者介绍为判断图像是否同面的消歧方法，这里把它们列入完整系统，没有说明它们通过什么重建流程产生相机结果。我只能猜测是把这些方法接入某个重建系统后比较。不会妨碍理解实验意图，但实际执行前必须说明组合方式，否则第一层比较的对象还不明确。这是正文未交代的实验接口，不宜替作者断言它已经解决。

### D. 修复动作由谁决定：可以读通，权限范围未明确

> “目标输出是具体的可疑匹配及其图像证据，随后由固定的几何程序执行修改。”
>
> “选择模型负责挑检查对象和修复动作。”

两句可以协调理解为“模型提议动作，固定程序验证并执行”，但正文没有直接说出这种分工。模型只是报告可疑匹配，还是也决定解除哪种关联，允许的动作空间是什么，仍不清楚。其大部分涉及作者已承认未完成的接受条件与方法设计；需要澄清分工，但不能据此指责稿件偷偷假设已有可靠修复算法。

## 四、不应误判为文字缺陷的未完成内容

> “尚未确定的关键步骤包括：如何挑出值得检查的匹配，如何选择下一张照片，如何把 VLM 指出的窗户区域对应到具体匹配点，以及何种检验足以接受修改、何时停止。”

这句话已经把方法层面的主要未知列出。不能将“没有交付区域到点的算法”误报为“读者不知道作者想做什么”。同样，目标失败样本集合与成功阈值未定，是作者承认的研究条件缺口。

这些未定项确实限制研究成熟度：当前可以评价方向与拟议检验逻辑，还不能评价算法可行性或预期效果。但就本次问题——短篇研究设想是否 human readable——它们被清楚地表达为未知，并未阻止独立理解。
