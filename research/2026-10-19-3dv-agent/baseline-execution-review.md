# 实验计划：Baseline 复现与失败留档

2026-10-20｜本轮执行方案｜尚未运行实验

本轮先跑现有重建模型，保存后续 failure analysis 所需的证据。顺序是 baseline → 失败分析 → toolkit → agent；工具集与 workflow 在实测之后决定。

## 1. 先跑四个 Baseline

| 顺序 / 模型 | 本轮作用 |
| --- | --- |
| 1 · DA3-Giant | 先核对官方参考结果，验证评测链路。 |
| 2 · VGGT | 基础对照，观察较早一代模型的失败。 |
| 3 · π³-X | 检查这些错误是否已被另一种重建方法解决。 |
| 4 · MapAnything | 寻找不同模型共同存在的问题。 |

四个模型都用官方预训练权重，记录代码 commit、权重版本与校验值。VGGT-Ω 拿到权重后补跑，使用官方重训练版本；访问仍待取得，见 Ω 复现说明。GGPT、GLUEMAP 等已有修复方法在初始失败整理后作为对照，不提前锁定为工具。

## 2. 数据范围与分析边界

| Benchmark / 本次规模 | 评价内容 |
| --- | --- |
| DTU-49：22场景 × 49张 | 物体表面重建。 |
| DTU-64：13场景 × 64张 | 相机估计；与 DTU-49 分开评价。 |
| ETH3D：11场景；ScanNet++：20场景 | 真实室内外 / 复杂室内，相机与几何。 |
| 7Scenes：7场景；HiRoom：24场景 | 手持室内 / 合成室内，相机与几何。 |

沿用 DA3 发布子集与评测协议，不等于各数据集完整官方榜单。四个模型共用场景、照片清单和顺序；DTU 分成两个配置，共 4 个模型 × 6 个数据配置。

开发分析另选 10 个 ScanNet++ training 场景，排除与评测场景重合者，按固定随机种子选取并保存 ID。第一批深入诊断和后续工具开发使用这批数据，结论先限定在室内场景；实际 ID 下载核对后确定。

五套评测数据可先跑并归档，不依据其中逐场景错误反复调整工具。需要用于开发的场景须事先划出，不再计入最终独立评测。原始输入和真值分开存放，模型只读 RGB。

## 3. 统一运行设置

只运行相机估计与预测相机下的重建，不输入真值相机、深度或内参。帧采样与图像顺序固定，各模型使用官方预处理并记录分辨率、裁剪及坐标变换。

主比较共用融合与评测流程，另外保存融合前的原始预测。首轮不添加 BA、修复或参数搜索。OOM、崩溃和无效输出均记入结果，不能静默删场景或减少输入。

## 4. 每个场景保存哪些结果

不能只存总分与截图。以“数据集 / 场景 / 模型 / 运行 ID”组织结果，保留原始数值和可追溯的图像索引。

| 保存项 | 具体内容 / 后续用途 |
| --- | --- |
| 输入与配置 | 图像 ID、顺序、路径、预处理变换、代码/权重版本及配置；排查输入或实现差异。 |
| 相机预测 | 每图内参、位姿、坐标约定；原始与评测对齐后的版本、对齐变换；定位错位相机。 |
| 逐视图几何 | 原始深度或局部点图、置信度、有效掩码，保留过滤前后结果；区分预测错误与过滤影响。 |
| 重建结果 | 未融合点云、融合点云/网格、融合参数、图像到三维点的对应关系；追踪重影、错形和缺失。 |
| 详细评测 | 逐场景指标、相机对误差、准确度与完整度误差图、有效评价区域；量化错误范围和影响。 |
| 跨视图证据 | 有效重叠区域的深度不一致图、重投影偏差、可见性掩码；检查不同视图是否冲突。 |
| 运行记录 | 耗时、峰值显存、异常、失败阶段与日志；区分工程失败与重建失败。 |

统一标明相机坐标约定、深度定义与尺度。不存在的模型输出标“无”；不为了补匹配或轨迹而另加 matcher。置信度保留模型原始含义，不跨模型直接比较数值。真值误差与不依赖真值的诊断分开保存。

## 5. 执行顺序与本轮交付

先锁定清单和配置，用 DA3 验证数据、坐标、融合与评测链路，再依次运行 VGGT、π³-X、MapAnything。每个预定运行都必须有成功结果或明确失败状态。不同设置的结果分开编号，不能用论文表格代替本次运行。

交付三样：① 逐场景结果总表：相机 AUC、几何准确度/完整度、Overall 或适用的 F-score、耗时、显存和状态；② 开发集案例包：同一场景四个模型并排，展示原图、预测和误差图，包含正常案例；③ 失败清单：现象、涉及模型、频率与分母、影响、原因证据及未知项。

先统计完整开发集，再按严重度检查案例。墙面重影等只是待核实的现象，不能直接断言相机或深度有错。模型运行失败与几何质量差分开统计。本轮完成后，再决定哪些重复出现且尚未解决的问题值得开发工具。
