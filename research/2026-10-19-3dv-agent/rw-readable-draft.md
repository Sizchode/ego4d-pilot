# 用图像证据纠正重建错误

Related-work survey｜2026-10-19｜研究设想，尚无实验结论

## 1. 从“两扇窗被认成一扇”说起

设想一栋建筑的转角两侧各有一扇相似的窗。照片 A 拍左窗，照片 B 拍右窗。重建程序把两扇窗的窗角错误匹配，认为它们是同一组三维点。为了满足这些匹配，程序可能把拍摄位置也算错，将两面墙拼到一起。这是说明问题的假设例子，不是已取得的实验结果。

为什么普通检查可能漏掉？程序会检查三维点投回照片后，是否落在匹配的像素附近。但相机位置和三维点可能一起被调整到错误的解，因此这个误差很小，也不保证两扇窗确实是同一扇。

现在加入已有照片 C：它同时拍到转角两侧的窗。并且能辨认出：A 中圆钟紧邻 C 的左窗，B 中铭牌紧邻 C 的右窗。这些线索支持它们属于两扇不同的窗。我们想让视觉语言模型（VLM）指出这组冲突，再检查 A、B 两个窗区域之间的匹配。若确认匹配错误，就解除这些关联，重新计算相机和三维点，保留其他可靠匹配。

## 2. 已有方法能做到哪一步

几何方法会检查和纠错。[COLMAP](https://demuc.de/colmap/) 会过滤不一致的匹配并联合优化相机与三维点。[Heinly 等（ECCV 2014）](https://www.cs.unc.edu/~jheinly/publications/eccv2014-heinly.pdf)已专门研究重复结构造成的错误恢复；[Progressive SfM](https://arxiv.org/html/1803.07349v1) 也能拆分、重算和重新合并模型。因此，发现错误后调用重建工具，本身不是新的研究贡献。

学习方法已经能利用图像消歧。[Doppelgangers++](https://arxiv.org/html/2412.05826v2) 判断两张相似照片是否真的看到同一表面；[MVDG](https://arxiv.org/html/2610.01098v1) 利用多张图像帮助判断。回到例子，它们也可能发现 A、B 属于不同窗户。[GLUEMAP](https://github.com/colmap/gluemap) 则把学习模型提供的局部几何与全局相机求解结合起来。我们不能假设这些方法只看数值、不理解图像，也不能只与弱配置的 COLMAP 比较。

VLM 已经参与过地图修复。[ThinkGraphs](https://arxiv.org/html/2606.31471v1) 在相机位置已知的情况下，判断地图里的两个对象记录是否其实是同一个物体，并合并重复记录。它支持“VLM 可以帮助判断物体身份”，但没有证明 VLM 能修复已经算错的相机位置。这是与我们问题最直接的区别。

## 3. 我们想验证什么，什么还没想清楚

唯一的核心假设是：在现有重建方法仍然出错的样本上，VLM 能否结合图像中的位置线索，找出影响相机求解的错误匹配？目标输出是具体的可疑匹配及其图像证据，随后由固定的几何程序执行修改。是否比已有消歧方法更准、能否带来真实相机改善，目前都没有答案。

Agent 的潜在作用是继续查证。例如 A、B 不足以判断时，从同一批已提供的照片里找 C，或调用局部匹配验证；这里不允许新增拍摄。只有查证确实改变修复决定，多步过程才有价值。若一次判断或非语言模型同样有效，就没有理由强调 Agent 或 VLM。

尚未确定的关键步骤包括：如何挑出值得检查的匹配，如何选择下一张照片，如何把 VLM 指出的窗户区域对应到具体匹配点，以及何种检验足以接受修改、何时停止。读出不同标识也不能直接批准解除匹配。这些是待设计的方法内容；目前还不是一套完成的算法。

## 4. 用哪些实验判断它是否值得做

数据集分工如下。每项结果只支持对应的结论，不把图像对判断正确直接当成相机恢复成功。

| 数据 | 检验的问题 | 结果与限制 |
| --- | --- | --- |
| [Doppelgangers / VisymScenes](https://arxiv.org/html/2412.05826v2) | A、B 这类错误关联能否被识别？ | 按图像对统计误接与误删；现有标签不直接给出每个匹配点的对错。 |
| [PhotoTourism](https://github.com/ubc-vision/image-matching-benchmark) | 修复后相机更准，还是只删了难图？ | 同时比较位姿误差与正确注册图像数；相机参考来自大规模重建，有自身偏差。 |
| [ETH3D（补充）](https://www.eth3d.net/data/schoeps2017cvpr.pdf) | 修改后真实表面是否更准确、完整？ | 用激光参考检验几何；其中是否有足够的目标错误样本，尚待确认。 |

两层对照必须分开。第一层比较 COLMAP、GLUEMAP 的完整重建结果；另将 Doppelgangers++、MVDG 接入同一个相机求解后端，比较筛选图像对后的结果，具体接入方式尚待确定。第二层让固定流程、非语言选择模型、一次性 VLM 和多步 VLM 使用相同照片、工具与求解器；选择模型提出检查对象和修复建议，由同一几何程序验证并执行。比较最终质量与全部运行时间，模型调用也计入成本。

还缺一项评测条件：既有这类自然错误、又有可信相机参考的样本集合，以及“正确恢复”的误差门槛，尚未确定。它们须在测试前确定；参考答案只用于离线评分，不交给 Agent 选动作。若修好的只是对象记录或图像对分类，相机没有改善，就不能声称解决了相机恢复。
